Linear Algebra I (Richard Earl, Oxford Prelims, Michaelmas). Index of topic notes.

The course in one line: solve linear systems by row reduction, then abstract the setting (vector spaces, bases, dimension, linear maps) so that matrices become **coordinates for linear maps**, and finally add geometry with inner products.

## Topics
1. [[LA1 - Linear Systems and Row Reduction]]: systems as matrices, EROs, elementary matrices, RRE form, solving systems *(Ch 1.1, 1.3)*
2. [[LA1 - Matrix Algebra]]: addition, multiplication, identity, inverses, $2 \times 2$ inverse, matrices commuting with everything *(Ch 1.2)*
3. [[LA1 - Inverses, Transposes and Orthogonal Matrices]]: transpose, special matrices, finding inverses with EROs, orthogonal matrices *(Ch 2)*
4. [[LA1 - Vector Spaces and Subspaces]]: axioms, examples, subspace test, sums and intersections *(Ch 3)*
5. [[LA1 - Span, Independence and Bases]]: span, independence, bases, coordinates, RRE tests, uniqueness of RRE, rank *(Ch 4)*
6. [[LA1 - Dimension]]: Steinitz exchange, dimension, extending and shrinking to bases, dimension formula, direct sums *(Ch 5)*
7. [[LA1 - Linear Transformations]]: linear maps, $\text{Hom}(V, W)$, isomorphisms, kernel and image, Rank–Nullity, criteria for invertibility *(Ch 6)*
8. [[LA1 - Matrices of Linear Maps]]: matrix of a map, composition = product, change of basis, similarity, row rank = column rank *(Ch 7)*
9. [[LA1 - Inner Product Spaces]]: bilinear forms, Gram matrices, inner products, Cauchy–Schwarz, orthogonal maps, complex inner products *(Ch 8)*

## Key Results at a Glance
- **Uniqueness of RRE form** (Thm 122) → rank is well-defined.
- **Steinitz Exchange** (Thm 127) → independent $\leq$ spanning (Thm 128) → dimension is well-defined.
- **Dimension formula** (Thm 139): $\dim(U + W) + \dim(U \cap W) = \dim U + \dim W$.
- **Rank–Nullity** (Thm 162): $\dim V = \text{rank}\,T + \text{nullity}\,T$.
- **Composition = product** (Thm 178) and **change of basis** $A = P^{-1}BP$ (Cor 185).
- **Row rank = column rank** (Thm 191).
- **Cauchy–Schwarz** (Prop 206): $|\langle v, w\rangle| \leq \|v\|\|w\|$.
